# خطة التطوير المفصلة: ميزات مصحف وِرد (ألوان التجويد، تفسير الآيات، خلفية المشاركة)

---

## ١. ملخص المتطلبات والالتزامات الهندسية الأساسية

تستهدف هذه الخطة إضافة ميزتين رئيسيتين لمصحف "وِرد" القرآني القائم على خطوط مجمع الملك فهد (QCF V2) مع تعديل مظهر مشاركة الصور:
1. **ألوان أحكام التجويد (Tajweed Colors)** باستخدام خطوط QCF Tajweed V4 الرسمية (Mushaf ID 19).
2. **تفسير الآيات (Tafsir for Ayah)** بشاشة قراءة مخصصة ومريحة، تدعم التخزين المحلي، العمل دون إنترنت، واختيار مصدر التفسير.
3. **تعديل لون خلفية مشاركة الآيات كصورة** من الأبيض إلى اللون السمني الدافئ المطابق للون ورق المصحف الشريف (`#F6F0E4`).

### الالتزامات والقيود الهندسية الصارمة:
- **عدم استبدال معمارية QCF V2**: يظل نظام QCF V2 هو الأساسي والمرجعي للعرض البصري.
- **عدم استخدام صفحات الصور (No Image-Based Mushaf)**: الحفاظ الكامل على صفحات المصحف المتجهة (Vector Layout).
- **الحفاظ على مصحف المدينة الحتمي 604 صفحات**: ثبات توزيع السطور الـ 15 ومواقع الكلمات وحدود الآيات وفواصلها.
- **عدم استخدام مقياس تمدد لكل سطر (No Per-Line FittedBox Scaling)** منعاً لتفاوت أحجام الكلمات بين السطور.
- **عدم تلوين أحرف التجويد يدوياً أو تكسير الكلمات**: التلوين يتم حصراً وتلقائياً عبر محرك خطوط QCF V4 بصيغة COLRv1 المتجهية.
- **الحفاظ التام على ألوان ورق المصحف الكلاسيكي**:
  - خلفية الورق: `#F6F0E4` (سمني عاجي كلاسيكي).
  - النص القرآني الأساسي: `#302923`.
  - الذهبي الهادئ للإطارات والزخارف: `#B58A4A`.
- **أمان مفاتيح الـ API**: عدم تضمين أي أسرار `client_secret` في كود التطبيق، والاعتماد على واجهات Content API الرسمية المفتوحة أو عبر وسيط آمن.

## ٢. تفاصيل التعديلات المعمارية والبرمجية

### أولاً: نظام ألوان التجويد (QCF Tajweed V4)

#### أ. تجريد طبقة العرض (Renderer Abstraction):
إنشاء تجريد مشترك لمنع تكرار كود الصفحة:
```text
QuranPageRenderer (عنصر العرض الأساسي الحاوي للهيكل الموحد)
 ├── QcfV2PageRenderer (عرض المصحف العادي بالخط الموحد)
 └── QcfTajweedV4PageRenderer (عرض مصحف التجويد بخطوط V4 الملونة)
```

**العناصر المشتركة بنسبة 100% بين النموذجين:**
- إطار مصحف المدينة الزخرفي (`_MushafPageFramePainter`).
- شريط الرأس العلوي (اسم السورة، رقم الجزء، والزخرفة المركزية).
- شريط التذييل السفلي (رقم الصفحة القرآني: ﴿ ٤٥ ﴾).
- شبكة السطور الـ 15 الحتمية وحساب التباعد بين الكلمات (`wordSpacing`).
- لافتات فواصل السور وبسملة بداية السور.
- مناطق استشعار لمس الآيات والضغط المطول (`AyahGestureRecognizer`).
- نظام التظليل الأخضر للعلامات المرجعية (بحيث يظل رقم الآية داخل التظليل نفسه بدون أي صناديق أو علامات هوامش إضافية).
- نظام التحديد المتعدد للآيات (`_selectedAyat`).

**الفرق الوحيد بينهما:**
- طبقة الخطوط (`FontLayer`):
  - في النمط العادي: استخدام الخط `QCF_P{page}` من مجلد `qcf_v2`.
  - في نمط التجويد: استخدام الخط `QCF_V4_P{page}` من مجلد `qcf_v4` (COLRv1)، حيث يتولى ملف الخط إبراز ألوان التجويد ذاتياً مع الحفاظ على لون الخط العام لباقي الأحرف.

#### ب. ترقية خدمة الخطوط (`QcfFontService`):
- دعم استدعاء وتخزين خطوط V2 و V4 بصورة مستقلة:
  - مسار CDN لخطوط V2: `https://verses.quran.foundation/fonts/quran/hafs/v2/ttf/p{page}.ttf`
  - مسار CDN لخطوط V4 (COLRv1): `https://verses.quran.foundation/fonts/quran/hafs/v4/colrv1/ttf/p{page}.ttf`
- مجلدات التخزين المؤقت المحلي:
  - `fonts/qcf_v2/p{page}.ttf`
  - `fonts/qcf_v4/p{page}.ttf`
- استراتيجية التحميل المسبق الذكية (Prefetching):
  - عند فتح صفحة يتم تحميل خط الصفحة الحالية، وفي الخلفية دون تعطيل واجهة المستخدم يتم تحميل خط الصفحة السابقة واللاحقة (`page - 1`, `page + 1`).
  - عدم تحميل الـ 604 خطوط دفعة واحدة مطلقاً.
- معالجة حالات التحميل بأمان (Graceful Fallback):
  - في حال لم يكتمل تحميل خط V4 بعد، يتم عرض الصفحة فوراً بخط V2 العادي دون أي انتظار أو تشوه بصري، وفور اكتمال تحميل خط V4 يتم إشعار الواجهة عبر `fontLoadedNotifier` لإعادة الرسم بسلاسة.
  - عدم دمج حروف V2 و V4 داخل نفس الكلمة أبداً.

#### ج. إعدادات نمط العرض (`QuranDisplayMode`):
- إنشاء تعداد:
  ```dart
  enum QuranDisplayMode {
    normal,
    tajweed,
  }
  ```
- حفظ اختيار المستخدم محلياً في `SharedPreferences` عبر `StorageService` و `QuranRepository`.
- إضافة مفتاح تبديل مبسط في:
  1. نافذة خيارات القراءة السريعة داخل المصحف (`QuranSettingsSheet`):
     - خيار واضح: **ألوان التجويد** [ تشغيل / إيقاف ].
  2. شاشة إعدادات التطبيق العامة (`SettingsPage`).

### ثانياً: شاشة وتجربة تفسير الآيات (Tafsir for Ayah)

#### أ. تجربة المستخدم (UX):
- عند الضغط المطول على أي آية تظهر خيارات الآية الحالية الخمسة:
  1. **تفسير**
  2. **حفظ كعلامة**
  3. **نسخ الآية**
  4. **مشاركة**
  5. **تحديد آيات متعددة للمشاركة أو الحفظ**
- عند اختيار **"تفسير"**:
  - فتح شاشة مخصصة كاملة/واسعة للقراءة المتأنية (`TafsirScreen`) وليس نافذة سفلية ضيقة.
  - الهيكل البصري للشاشة:
    - شريط علوي: زر العودة، اسم السورة، ورقم الآية.
    - بطاقة علوية مميزة: نص الآية القرآنية بالرسم العثماني الأصيل (`UthmanicHafs`) واضحة ومفصولة بصرياً.
    - فاصل زخرفي هادئ.
    - قائمة منسدلة أنيقة لاختيار كتاب التفسير (مع إظهار اسم التفسير والمؤلف).
    - مساحة قراءة واسعة لنص التفسير باللغة العربية (RTL)، بخط واضح ومريح للعين (`Cairo` أو خط قراءة مناسب)، وارتفاع سطر رحب (Line Height 1.7+).
    - أداة تحكم سريعة بحجم خط التفسير لتناسب راحة القارئ (دون أي تأثير على حجم خط صفحات المصحف).
    - دعم المظهر الليلي والمظهر الفاتح الكلاسيكي (ورق المصحف).

#### ب. المعمارية وإدارة البيانات (`TafsirRepository`):
- تعريف النماذج:
  ```dart
  class TafsirResource {
    final int id;
    final String name;
    final String authorName;
    final String language;
    ...
  }

  class Tafsir {
    final String verseKey;
    final int resourceId;
    final String resourceName;
    final String text;
    ...
  }
  ```
- تعريف العقد التجريدي:
  ```dart
  abstract class TafsirRepository {
    Future<List<TafsirResource>> getAvailableTafsirs();
    Future<Tafsir?> getTafsirForAyah({
      required String verseKey,
      required int tafsirResourceId,
    });
  }
  ```
- إنشاء فئة التخزين المؤقت المحلي (`TafsirCache`):
  - المفتاح: `tafsir:{resourceId}:{verseKey}` (مثال: `tafsir:16:2:255`).
  - التحقق أولاً من الكاش المحلي -> إذا وجد يُعرض فوراً دون انتظار.
  - إذا لم يوجد -> جلبه من المصدر المعتمد وحفظه محلياً ثم عرضه.
  - في حالة انقطاع الإنترنت مع وجود كاش -> يظهر النص المخزن بسلاسة.
  - في حالة انقطاع الإنترنت بدون كاش -> تظهر رسالة واضحة بحالة عدم الاتصال مع زر إعادة المحاولة.
- مصادر التفسير المعتمدة المتاحة:
  - التفسير الميسر (ID: 16) - وهو التفسير الافتراضي.
  - تفسير السعدي (ID: 91).
  - تفسير ابن كثير (ID: 14).
  - تفسير البغوي (ID: 94).
  - تفسير الطبري (ID: 15).
  - تفسير القرطبي (ID: 90).
  - التفسير الوسيط للطنطاوي (ID: 93).
- تنظيف وسوم الـ HTML (مثل `<span class="blue">`) لضمان ظهور النص العربي نقياً ومتناسقاً.
- إضافة إعداد التفسير الافتراضي في إعدادات التطبيق (`DefaultTafsirResource`).

### ثالثاً: تعديل لون خلفية مشاركة الآيات كصورة

- **المشكلة الحالية**: عند مشاركة الآيات كصورة في نمط المدينة (`QuranShareTheme.medina`)، كانت بعض المساحات تظهر بيضاء نقية (`#FFFFFF` أو `#FAF7EE`).
- **التعديل المطلوب**:
  - تغيير خلفية بطاقة المشاركة في نمط المدينة لتكون بلون ورق المصحف السمني الدافئ الأصيل (`#F6F0E4`).
  - تعديل خلفيات العناصر البيضاء في صندوق المشاركة لتتناغم مع هذا اللون.
  - الحفاظ التام على باقي العناصر: الأطر الذهبية والبرونزية، الوريدات القرآنية الفاصلة بين الآيات، اسم السورة بالأعلى، والتذييل باسم التطبيق والآيات دون أي تغيير آخر.

## ٤. خطة الفحص وقبول الجودة (Acceptance Testing)

### أولاً: فحص صفحات المصحف في النمطين (العادي والتجويد)
سيتم فحص الصفحات المحددة في المتطلبات:
- **صفحة 1** (سورة الفاتحة): فحص الإطار الخاص والترويس والوسطية وثبات الحجم.
- **صفحة 2** (بداية البقرة): فحص الآيات الخمس الأولى وتطابق الخطوط.
- **صفحة 3، 4، 5**: فحص استمرارية التوزيع وتناسق أسطر الـ 15 وسطراً.
- **صفحة 10**: فحص علامات الحزب والأرباع وعلامات الآيات.
- **صفحة 20**: فحص السطور المشتركة بين عدة آيات.
- **صفحة 255** (آية الكرسي): فحص الآية الكريمة، ثبات الهامش، عدم وجود تفاوت في أحجام الكلمات.
- **صفحة 604** (نهاية المصحف - المعوذات): فحص لافتات السور الثلاث المتتالية وثبات الارتفاع.

**لكل صفحة يتم التأكد من:**
- ظهور ألوان التجويد الدقيقة تلقائياً من خط V4 بدون أي تشوه.
- ثبات أبعاد الصفحة وارتفاع السطور ومواقع الكلمات بنسبة 100%.
- عدم حدوث أي انزياح أو شفت في خط الأساس (No baseline shift).
- سلامة الضغط المطول، التحديد المتعدد، والتمييز الأخضر للعلامات المرجعية.
- سلاسة تقليب الصفحات والتحميل المسبق للخطوط المجاورة.

### ثانياً: فحص التفسير
- الضغط المطول على آية الكرسي (2:255).
- اختيار "تفسير" -> فتح شاشة التفسير المستقلة.
- التأكد من قراءة مفتاح الآية بدقة (`2:255`) وعرض نص الآية القرآني بالأعلى والتفسير الميسر المعتمد.
- تجربة تغيير المصدر (مثلاً: تفسير ابن كثير أو السعدي).
- التحقق من التخزين في الكاش -> قطع الاتصال -> إعادة فتح الآية والتأكد من فتح التفسير مباشرة في وضع Offline.

### ثالثاً: فحص مشاركة الآيات كصورة
- فتح نافذة المشاركة واختيار توليد صورة في نمط المدينة.
- التأكد من أن لون الخلفية أصبح هو اللون السمني الدافئ لورق المصحف الشريف (`#F6F0E4`) بدلاً من الأبيض.
- التأكد من ثبات وتناسق كافة الخطوط والزخارف والنصوص.
